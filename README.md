# Rapid KL Bus Arrival Prediction
Predicting Rapid KL bus arrival times at each stop using machine learning, to give commuters more reliable waiting information.

# Problem Statement
Many people use the bus Rapid KL every single day but some user are not familiar with bus environment. So the MyRapid Pulse app is created but the problem is the app shows when a bus leaves the terminal but not when it will reach each stop. Also the users say the times are not always accurate. People wait at the bus stops without knowing when the bus will come, which a waste of time and some of them give up and take the Grab or taxi (Khazanah Research Institute, 2025).
